# File Sentence Analyzer

A beginner-friendly Python project that demonstrates **file handling** and **basic text analysis**.  
The program reads a sentence from a text file (`input.txt`) and calculates:

- Number of words
- Average word length
- Longest word
- Shortest word

This project is part of my Python learning journey and portfolio building. It showcases practical skills that can be applied to real-world freelance tasks such as text processing, file automation, and data cleaning.
